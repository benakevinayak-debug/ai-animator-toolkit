# AI Animator Toolkit

A small open-source browser toolkit for 2D animators and creative developers.

## Features

- Shot planning with duration and camera notes
- Local production board using browser localStorage
- AI animation prompt builder
- Responsive interface
- No backend or paid API required

## Why this project exists

Animation production often involves repeating small planning tasks before the actual animation begins. This project explores simple browser-based tools that can make shot planning and AI-assisted ideation faster.

## Run locally

No build system is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Start planning shots.
